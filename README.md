# 💻 Exemplos JavaScript

Repositório educacional criado para armazenar exemplos práticos de **JavaScript** desenvolvidos e demonstrados em sala de aula.

O objetivo deste projeto é auxiliar os alunos na aprendizagem dos principais fundamentos da linguagem JavaScript, utilizando exemplos simples, comentados e de fácil compreensão.

## 🎯 Objetivo

Apresentar os conceitos fundamentais de JavaScript de forma prática, permitindo que os alunos compreendam como a linguagem funciona e como pode ser utilizada para adicionar lógica e interatividade às páginas Web.

## 📚 Conteúdos abordados

Durante os exemplos são trabalhados conteúdos como:

- Introdução ao JavaScript;
- Uso do `console.log()`;
- Tipos de dados;
- Variáveis com `let`, `const` e `var`;
- Operadores;
- Estruturas condicionais `if`, `else` e `else if`;
- Operadores lógicos;
- `switch case`;
- Operador ternário;
- Estruturas de repetição `for`, `while` e `do...while`;
- Funções;
- Arrays;
- Tratamento de erros com `try`, `catch` e `finally`;
- Integração entre HTML e JavaScript;
- Eventos com `onclick`;
- `alert()` e `prompt()`;
- Manipulação de elementos HTML;
- Introdução ao DOM;
- `document.getElementById()`;
- `.innerHTML`;
- `.value`;
- Alteração de estilos com `.style`;
- Exibição e ocultação de elementos.

## 🧩 Exemplos de interação

Os exemplos permitem observar na prática funcionalidades como:

- Exibir mensagens para o usuário;
- Executar funções ao clicar em botões;
- Alterar textos da página;
- Alterar cores e estilos;
- Esconder e mostrar elementos;
- Capturar informações digitadas pelo usuário;
- Exibir informações dinamicamente na página.

## 📂 Estrutura básica

```text
exemplos-javascript/
│
├── index.html
├── script.js
└── script2.js
````

O arquivo HTML é utilizado para estruturar a página e os arquivos JavaScript apresentam exemplos dos conceitos estudados.

## 🧠 Aprendizagem

A proposta deste repositório é permitir que os alunos possam consultar, executar, modificar e testar os códigos apresentados durante as aulas.

A recomendação é alterar valores, textos e condições dos exemplos para observar como cada modificação interfere no funcionamento do programa.

## 🛠️ Tecnologias utilizadas

* HTML5
* JavaScript
* Visual Studio Code
* Navegador Web
* DevTools / Console do navegador

## 🎓 Finalidade

Este projeto possui finalidade exclusivamente **educacional**, sendo utilizado como material de apoio para demonstrações, estudos e atividades práticas realizadas em sala de aula.
